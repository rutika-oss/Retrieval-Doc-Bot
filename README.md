# 📌 Retrieval Doc Bot | AI-Powered Document Chatbot

The Retrieval Doc Bot is an AI-powered chatbot application designed to retrieve, analyze, and answer questions from uploaded documents using Retrieval-Augmented Generation (RAG) and Natural Language Processing (NLP). The project enables users to interact with PDFs and documents in a conversational way using Large Language Models (LLMs).

## 🎯 Key Objectives

* Build an AI-powered document question-answering system
* Enable intelligent retrieval of document-based information
* Improve search accuracy using vector embeddings
* Provide real-time conversational responses
* Simplify document analysis and knowledge extraction
* Implement Retrieval-Augmented Generation (RAG)

## 💻 Commands to Run the Project

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Mac/Linux

```bash
source venv/bin/activate
```

### Install Required Libraries

```bash
pip install -r requirements.txt
```

### Run Streamlit Application

```bash
streamlit run app.py
```
